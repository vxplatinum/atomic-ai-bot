# This is the part of Atomic AI Bot project.

### Main Information
The project is built on a service-oriented architecture; this component serves as the front end for the web service and acts as the web interface for the backend.

### Technologies
- Node.js 20+ - runtime
- React - UI library
- Vite - dev server and production build
- React Router DOM - client-side routing
- Tailwind CSS - styling
- ESLint - linting

### Commands
1. Install dependencies
```bash
npm install
```

2. Add `.env` file with the same variables as in `.env.example`

3. Run frontend project
- development mode
```bash
npm run dev
```

- production mode (static build + local preview)
```bash
npm run build
npm run preview
```
